# Архитектура проекта

Статус: Реализовано

- [Компоненты, контракты и API](design.md).
- [Реестр архитектурных решений](decisions/README.md).
- [Требования и приёмка](../product/requirements.md).

| Область | Реализация |
| --- | --- |
| Источники | Проверяемая загрузка Freddie Mac и UCI, импорт и метаданные |
| Синтетика | Тринадцать сценариев, отдельная формула и компоненты истины |
| CSV | Парность, типы, конечность, пропуски факторов, категории, даты и описательный профиль |
| Обучение | Одна рабочая GAM; семь исследовательских семейств, поиск на валидации |
| Атрибуция | Линейные/сплайновые/квадратичные термы, EBM и TreeSHAP |
| Надёжность | Бутстрэп, профили параметров, материальность остатка, принятие и отказ |
| Диагностики | Глобальная важность отдельно от вкладов; тип формы условного сечения |
| Сохранение | Состояние, модели, прогнозы, локальные термы, сечения, манифест |
| Интерфейс | Локальный FastAPI, отдельный процесс расчёта, отмена и JSON/CSV |
| LLM | Pydantic AI и OpenRouter, выбор проверенных фактов, контролируемый AG-UI поток; живая проверка семи вопросов и браузера завершена |

Описание каждого контракта хранится в одном документе или схеме, остальные разделы ссылаются на него. Технический стек закреплён в `pyproject.toml` и `uv.lock`; переносимость Docker пока ограничена отсутствием работающего демона в проверочном окружении. Проверки и команды — в [руководстве разработки](../development/README.md).
