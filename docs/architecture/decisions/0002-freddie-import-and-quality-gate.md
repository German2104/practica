# ADR 0002 Импорт Freddie Mac и проверка пригодности

Статус: Реализовано

## Контекст

Для начала реализации доступен открытый архив Release 47 с примерами формата. Полная годовая выборка требует аккаунта Clarity, которого пока нет. При первичном чтении образца обнаружены 1000 выдач и 1011 записей истории по 12 кредитам; идентификаторы между файлами не пересекаются. Объединение таких файлов не даст обучающую таблицу.

## Варианты

- Изменить идентификаторы ради объединения: отвергнуто, поскольку это создаст вымышленные связи.
- Остановить разработку до получения аккаунта: не позволяет проверить независимый импорт.
- Реализовать получение официального образца, строгий импорт и отдельную проверку пригодности: выбран этот вариант.

## Решение

Загрузчик сохраняет исходные архив и документацию без изменений, с URL, контрольной суммой, размером и временем получения. Открытый образец помечается как `format_sample`, а не годовая исследовательская выборка. Закреплённые контрольные суммы защищают от незаметной смены версии источника; при несовпадении загрузка завершается ошибкой.

Читатель поддерживает стандартный Release 47: 31 колонка выдач и 35 колонок истории. Он принимает либо ZIP с однозначной парой файлов, либо два локальных файла. Архив читается без извлечения путей на диск. Число полей, даты, ключи и числовые значения проверяются до подготовки таблицы. Специальные коды отсутствующих значений преобразуются по словарю. Названия и позиции полей соответствуют официальному файлу схемы, а не старому релизу.

Профилирование всегда предшествует объединению. Дубликаты, некорректные поля, пустое пересечение или отсутствие выдачи для кредита из истории блокируют экспорт. Отчёт сохраняется даже при отказе. Неполные колонки не заполняются догадками. Для выбранных месяцев экспортируется только общая подвыборка с календарными датами, а входы/выходы отдельно считаются в отчёте. Если пересечение пусто, экспорт завершается ошибкой.

NPV, EC, PD и LGD не создаются импортёром. Текущий и исходный LTV сохраняются отдельно. Это вход для последующего определения целевой метрики, а не готовая таблица обучения.

## Последствия

Добавляются пакет `ec_analysis.data`, CLI подготовки данных, агрегированный отчёт качества и тесты на согласованных искусственных строках официального формата. Полные исходники и подготовленные кредитные записи исключаются из Git. Опубликованные примеры не используются для заключений о качестве модели.

## Проверка

Проверить получение и повторное использование файлов по контрольным суммам, ширину строк и даты, преобразование процентов и кодов пропусков, уникальность ключей, отсутствие вымышленных связей, сохранение дат и учёт состава подвыборки. Официальный образец должен дать отчёт с нулевым пересечением и отказ экспорта. Согласованные искусственные файлы должны давать ожидаемую таблицу.

29 сентября 2026 года три официальных файла получены и повторно проверены из локального кэша. [Отчёт образца](../../../data/reports/release47-public-quality.json) подтверждает 1000 выдач, 1011 записей истории и нулевое пересечение; CLI возвращает код 2. Тесты подтверждают успешный экспорт согласованных искусственных строк, единицы, даты, состав подвыборки, отказ при дефектах и сохранность исходников. Всего в проекте проходят 29 тестов; Ruff и mypy также проходят. Годовая исследовательская выборка ещё не проверена. Команды и ограничения — в [описании импорта](../../data/release47-import.md).
