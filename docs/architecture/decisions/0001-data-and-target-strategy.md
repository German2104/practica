# ADR 0001 Данные и целевая метрика первого эксперимента

Статус: Черновик

## Контекст

Постановка требует факторного анализа NPV с проверкой на синтетических и реальных данных. Ипотечные открытые наборы содержат наблюдения по кредитам, но не предоставляют готовый банковский расчёт NPV/EC. Без определения целевой метрики сравнение ML-моделей не отвечает бизнес-задаче.

## Варианты

| Вариант | Преимущество | Ограничение |
| --- | --- | --- |
| Только синтетика | Известна формула; можно проверить восстановление эффектов | Не подтверждает работу на реальном портфеле |
| Freddie Mac и отдельный расчёт метрики | Есть помесячная история для сравнений | Нужны доступ к данным и явные допущения расчёта |
| FHFA PUDB | Доступны ипотечные срезы | Не заменяет историю тех же кредитов между месяцами |
| Наблюдаемая альтернативная метрика | Позволяет проверить технический метод без конструирования NPV | Такой результат нельзя называть выполнением основного NPV-кейса |

## Предлагаемое решение

Сначала получить небольшую выборку Freddie Mac и проверить её состав. Синтетику использовать как самостоятельный контрольный набор. Затем определить модельный NPV на доступных входах либо получить бизнес-расчёт; выбор формулы, горизонта и параметров пока открыт. Полный EC в первый эксперимент не включать без его определения.

Источники и порядок получения находятся в [документе данных](../../data/README.md). Выбор целевой формулы остаётся предложением. Открытый образец формата уже получен и проверен по [ADR 0002](0002-freddie-import-and-quality-gate.md), но согласованной годовой выборки для обучения и проверенного расчёта реальной целевой метрики пока нет.

## Последствия

Входы разделяются на наблюдаемые, оценённые и заданные допущениями. Расчёт метрики версионируется отдельно от модели объяснения. Подготовка данных должна сохранять реальные даты и отсекать недоступные на дату входы. Отчёт на модельном NPV показывает ограничения допущений.

## Проверка

- Файлы, ключи, даты и единицы измерения подтверждены по словарю источника.
- Контрольные примеры расчёта метрики воспроизводятся независимо от ML-модели.
- Есть анализ чувствительности к недостающим параметрам и проверка утечек будущей информации.
- Полученные результаты различают синтетическую проверку и эксперимент на реальных входах.

Результат проверки: не выполнена; решение остаётся черновиком.
