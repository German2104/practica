# ADR 0003 Сопоставимое обучение и независимая оценка

Статус: Реализовано

## Контекст

Первый запуск Ridge использовал оба периода для обучения и весь портфель для расчёта ошибки изменения. Нужен проверяемый протокол без будущих целевых значений в обучении. Доступна парная синтетика T0/T1; многопериодная реальная история ещё не получена.

## Варианты и решение

Случайное разделение строк отвергнуто из-за пересечения кредитов. Полная проверка на трёх последовательных календарных окнах пока невозможна. Выбран ограниченный протокол `forward_grouped_v1`: детерминированно разделять идентификаторы на обучение/валидацию/тест в пропорции 60/20/20; обучать только на T0 обучающих кредитов. Качество кандидатов оценивать на T1 валидационных кредитов. Ошибку портфельного изменения считать на T0/T1 той же независимой валидационной подвыборки.

Выбор прогнозной модели — минимум RMSE на валидации с детерминированным разрешением равенства. После выбора оценивать только выбранную модель на тестовых кредитах без переобучения. Внутренние проверки EBM используют только обучающую часть. Тестовые целевые значения не участвуют в выборе. Это перенос T0→T1 на других кредитах, а не доказательство устойчивости на нескольких временных окнах. При наличии `as_of_date` проверять порядок дат T0/T1; иначе явно указывать только относительные периоды.

Кандидаты: среднее, Ridge с масштабированием, аддитивный Gaussian GAM на сплайновых базисах и Ridge, XGBoost, EBM. Для GAM применяется `SplineTransformer` без произведений признаков: он моделирует гладкие одномерные функции, а не взаимодействия. Параметры фиксируются до запуска; оптимального подбора гиперпараметров этот этап не заявляет. Все преобразования, включая импутацию и категории, обучаются внутри одного pipeline только на обучающих данных. Категориальные признаки кодируются одинаково для всех кандидатов; качество кодирования оценивается отдельно при появлении реальных данных.

В сравнении сохранять RMSE/MAE, фактическое и предсказанное изменение, подписанный и абсолютный остаток, время, параметры и явные ошибки кандидатов. Остаток делить на модуль изменения только выше порога, связанного с масштабом портфеля. Отсутствующие устойчивость и атрибуция остаются неизвестными. Выбранная прогнозная модель не считается надёжным объяснением.

## Контракты и воспроизводимость

Расширить `AnalysisState` метаданными протокола и независимой тестовой оценкой; результаты неуспешных кандидатов сохранять с причиной. Основные суммы состояния относятся ко всему входному портфелю, метрики кандидатов — только к указанной проверочной подвыборке. Пока вклады не вычисляются, весь общий сдвиг остаётся в верхнеуровневом остатке.

CLI сохраняет JSON-отчёт, списки кредитов разбиения, прогнозы, обученные pipeline и контрольные суммы данных, кода и зависимостей. Новый каталог запуска не должен затирать существующий. Загрузка чужих сериализованных моделей не добавляется.

Истинные формулы синтетики и значения её компонентов сохранять отдельно от обучающего CSV. Проверять линейность, порог, насыщение, U-образность и взаимодействие; эти компоненты не объявлять истинными SHAP-вкладами.

## Проверка и последствия

Тестами подтверждены отсутствие пересечений, обучение преобразований только на T0, независимость выбора от тестовых ответов, расчёт ошибки на отложенных кредитах, неизвестные категории/пропуски, отказ при неконечных числах, статусы недоступных/неуспешных кандидатов и сохранение моделей с контрольными суммами. 29 сентября 2026 года прошли 51 тест, Ruff и mypy; все пять кандидатов обучились на восьми сценариях. [Измеренные результаты](../../ml/synthetic-comparison-v1.md) сохранены. Многопериодная проверка, поиск параметров, атрибуция и устойчивость остаются отдельными этапами.

Рабочий выбор семьи заменён [ADR 0010](0010-single-gam.md);
исследовательские сравнения этой записи сохраняются.
