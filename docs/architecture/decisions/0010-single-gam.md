# 0010. Одна модель для рабочего анализа

Статус: Реализовано

## Контекст и варианты

Пользователь поручил закрепить одну устойчивую модель. Это заменяет выбор семьи
для каждого рабочего запуска из ADR 0003/0005/0009; исследовательское сравнение
сохраняется для исходного задания. Рассмотрены Ridge (ограничена линейностью),
XGBoost/EBM и GAM с парами. Историческая валидация v3: GAM с парами прошла
8 из 13 синтетических сценариев и все три окна UCI. Эти данные используются
для разработки, а не как независимая оценка новой версии.

## Решение и контракт

Рабочая семья — `stable_gam`: кубические сплайны каждого числового фактора,
категориальные индикаторы, произведения базисов только разных исходных факторов
и единая Ridge-регрессия. Убираем квадраты и произведения базисов внутри одного
фактора из прежней `gam_pairwise`: сплайн уже описывает его нелинейность.
Базисы и их произведения центрируются по обучающей выборке. Парные коэффициенты
получают в 1000 раз больший квадратичный штраф, чем основные; это ограничивает
слабые взаимодействия. Множитель выбран на валидации разработки seed 2027
из 1, 10, 100, 1000, 10000, затем фиксируется до подтверждения seed 2028. Шесть узлов,
степень 3, линейная экстраполяция; три заранее заданных alpha: 0.1, 1, 10.
Лимит 2500 термов защищает от чрезмерного расширения.

Препроцессор и регрессия обучаются только на T0 обучающих клиентов. Alpha
выбирается по RMSE валидации T1. После этого одна модель замораживается;
тест не выбирает параметры и не вызывает переход к другой семье.
Рабочий API и интерфейс всегда выполняют 20 бутстрэп-переобучений и проверку
чувствительности ко всем трём alpha. Исследовательский CLI по умолчанию
сохраняет прежнее сравнение; явная политика `fixed_gam` запускает новую семью.

Точный расчёт вклада: сумма значения каждого терма на T1 минус сумма на T0.
Основные термы группируются по фактору, парные — по паре, без двойного учёта.
Метод `centered_cross_factor_gam_delta_v1`. Подписанный остаток равен
фактическому изменению минус сумме вкладов. Это описание модели, не причинный эффект.

## Последствия и проверка

Название `stable_gam` обозначает версию алгоритма, а не гарантию надёжности.
Пороги ADR 0007 и проверка параметров ADR 0009 остаются прежними. При провале
показывается отказ; запасной семьи нет. На новых данных параметры и коэффициенты
обучаются заново внутри той же семьи. Старые эксперименты и архив исходников v3
сохраняются отдельно; текущий код больше не воспроизводит их контрольную сумму.

Проверяем клонирование при бутстрэпе, отсутствие внутригрупповых произведений,
баланс, категории/пропуски и смену периодов. После фиксации реализации проводим
отдельную серию seed 2028, 13 сценариев по 5000 клиентов и три окна UCI.
Фактические результаты и ограничения сохранены в [методике](../../ml/single-gam.md).

Проверено: 123 теста, независимые серии завершены. Кредитный пример принят;
всего 8/13 + 1/3. Остальные результаты отклонены без смены семьи.
[Методика и фактические измерения](../../ml/single-gam.md).
