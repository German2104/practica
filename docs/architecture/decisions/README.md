# Архитектурные решения

Статус: Принято

ADR создаётся для существенного выбора с альтернативами. Небольшая локальная правка отдельного ADR не требует. Файл называется `NNNN-short-title.md` и начинается со статуса «Черновик», «Принято» или «Реализовано».

| [0002 Импорт и проверка пригодности](0002-freddie-import-and-quality-gate.md) | Реализовано | Сохранение источников, строгий формат Release 47 и отказ от некорректного объединения |

## Содержание записи

1. Контекст и проблема.
2. Рассмотренные варианты и их ограничения.
3. Решение; для черновика — предлагаемое решение и открытые вопросы.
4. Последствия и затронутые контракты.
5. Способ проверки и, после выполнения, фактический результат.

Утверждённый выбор сохраняется в истории. Заменяющее решение создаётся новым номером и ссылается на предыдущее; в старой записи добавляется ссылка «Заменено ADR …». Статусы в реестре обновляются вместе с записью. Переписка и промежуточные рассуждения исполнителей в ADR не переносятся.
