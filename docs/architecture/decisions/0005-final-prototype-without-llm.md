# ADR 0005 Завершение прототипа без LLM и улучшение качества

Статус: Принято

Исключение LLM заменено [ADR 0009](0009-complete-analysis-and-verified-llm.md) по последующему запросу пользователя выполнить исходное задание полностью. Остальные правила этой записи сохраняются.

## Контекст и решение

Пользователь поручил завершить реализацию, улучшить метрики, пропустить LLM и подготовить отчёт по всему выполненному. Это уточняет границы MVP: численный анализ, интерфейс и воспроизводимый отчёт обязательны; генерация текста моделью, AG-UI и ключи LLM исключены из обязательного пути. Результат объясняется проверенными таблицами, графиками и детерминированным текстом. Исходный кейс не меняется.

Повторять подбор по уже просмотренному финальному тесту нельзя. Исторические эксперименты сохраняются. Для разработки используется прежняя синтетика seed=42; пространство параметров задаётся явно. В каждой семье вариантов выбирается лучший по валидации, фиксируются все попытки, затем сравниваются семьи. Для независимого подтверждения используются новые данные seed=2026 и заранее зафиксированный протокол. Формула синтетики не передаётся в обучение.

## Варианты и критерии

- Сохранение фиксированных параметров оставляет заметные ошибки и не исполняет запрос на улучшение.
- Ручная подгонка факторов под формулу или отбор удачного теста отвергнуты.
- Выбран ограниченный поиск регуляризации, сложности сплайнов и параметров бустинга. Если расширяются базисные функции, они строятся общим алгоритмом из обучающих признаков.

Реализуемое пространство включает три фиксированных профиля на семейство (один для среднего), сохраняет все попытки и время. Добавлены общий квадратичный базис и сплайновая модель с парными произведениями. Ни пороги, ни коэффициенты генератора им не передаются. Одномерные произведения группируются в исходный фактор, двумерные — в пару; база и баланс проверяются тем же контрактом. Размер расширения ограничен 2500 термами. Более дорогой исследовательский вариант EBM с 20000 раундов и 128 ячейками взаимодействий не вошёл в рабочее пространство: на кредитной валидации он занял 186,36 с и не улучшил более дешёвый вариант.

Для нескольких реальных окон назначение кредита в обучение, валидацию или тест определяется SHA-256 от seed и id. При изменении состава окна оставшиеся кредиты сохраняют группу. Это исключает переход бывших тестовых клиентов в обучение соседнего окна. Пропорции приблизительно 60/20/20; историческое точное случайное разбиение остаётся доступным отдельно.

Предварительная проверка пригодности объяснения должна учитывать качество прогноза, остаток, численную корректность, устойчивость и знак существенных эффектов. Пороги задаются до подтверждающей проверки и сохраняются в результате. Устойчивость ошибочной модели не даёт положительного заключения; сценарий скрытой смены режима должен завершаться отказом. Для отсутствующей оценки возвращается «недостаточно проверок», а не успех.

## Полный результат

1. Получение и подготовка доступных реальных данных с версией целевой формулы и ограничениями.
2. Сравнение моделей, подбор параметров, независимые проверки и явные случаи отказа.
3. Вклады, взаимодействия, остаток, зависимости и устойчивость; сохранённые расчёты.
4. Веб-интерфейс загрузки/демонстрации, сравнения и экспорта; запуск без ключей LLM.
5. DOCX и PDF по ГОСТ 7.32–2017 с методологией, измеренными результатами, исходниками, ограничениями и проверкой страниц. Неизвестные реквизиты титульного листа остаются полями для заполнения.

## Проверка

Тесты границ разбиений, отсутствия утечек, подбора только по валидации, баланса, отказов, HTTP и пользовательского пути. Проверка всех ссылок на расчёты, воспроизведение ключевых запусков и визуальная проверка страниц отчёта. Завершение определяется по этим результатам, не по одному удачному RMSE. Состояние выполнения — в плане и итоговом аудите.

Рабочий выбор семьи заменён [ADR 0010](0010-single-gam.md);
исследовательские сравнения этой записи сохраняются.
