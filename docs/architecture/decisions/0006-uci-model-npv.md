# ADR 0006 Открытый кредитный портфель и модельный NPV

Статус: Принято

## Контекст и варианты

Годовой набор Freddie Mac требует отсутствующего аккаунта. Публичный образец формата не даёт связанных наблюдений. Для проверки реальных входов выбран UCI Default of Credit Card Clients, DOI 10.24432/C55S3H: 30000 клиентов, месячные счета и статусы платежей за апрель–сентябрь 2005 года, лицензия CC BY 4.0. Это карточные счета Тайваня, не ипотека Freddie Mac. Источник: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients .

Только синтетика не проверяет реальные распределения; ожидание аккаунта не даёт продвижения. Использовать метку будущего дефолта для объяснения предыдущих месяцев запрещено. Выбран доступный панельный источник с отдельным демонстрационным расчётом стоимости. Этот ADR дополняет и уточняет черновик ADR 0001 для текущего прототипа; исходное ипотечное направление сохраняется как возможность расширения.

## Формула и границы

Цель `model_npv` — модельный NPV одномесячного положительного требования, единица — новый тайваньский доллар. На дату периода известны сумма счёта `volume` и статус платежа. При фиксированных годовых ставках купона c=0.18 и дисконтирования d=0.06, LGD=0.60:

`expected_cashflow = volume * ((1 - pd) * (1 + c/12) + pd * (1 - lgd))`;

`model_npv = expected_cashflow / (1 + d/12) - volume`.

Месячная PD задаётся учебным сценарием: статусы ≤0 → 0.01; 1 → 0.04; 2 → 0.10; 3 → 0.20; ≥4 → 0.40. Это допущения, не оценки эмпирического риска. Они хранятся отдельно и доступны для анализа чувствительности. ML получает только `volume` и `pd`; исходный статус сохраняется в происхождении, а не дублируется коррелированным фактором. Демографические данные и будущая метка дефолта не используются. Отрицательные счета не являются положительными требованиями и исключаются с явными счётчиками по периоду; нулевые счета допускаются.

Поддерживаются выбранные соседние месяцы с одинаковыми клиентами и датами. Анализ касается парной подвыборки; исключения и суммы публикуются. Для временной проверки фиксируются несколько последовательных окон; одна и та же группа тестовых клиентов не участвует в подборе.

## Последствия и проверка

Результат демонстрирует приближение заданной оценки на реальных входах. Он не подтверждает банковский NPV, калибровку PD или точность прогноза дефолта. Проверяются SHA-256 источника, схема и месяц каждой колонки, отсутствие будущих признаков, контрольные формулы, баланс и чувствительность к допущениям. В отчёте реальные наблюдения, заданные параметры и модельные ответы маркируются отдельно.
