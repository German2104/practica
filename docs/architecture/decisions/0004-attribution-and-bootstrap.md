# ADR 0004 Разложение прогноза и устойчивость вкладов

Статус: Реализовано

## Контекст и варианты

После ADR 0003 есть обученные pipeline и независимая проверка прогноза. Глобальная важность не объясняет изменение T0→T1. Выбрано разложение одной фиксированной модели в двух периодах; отдельное обучение моделей периодов и принудительное обнуление остатка отвергнуты.

## Решение

Разность вкладов линейных коэффициентов или аддитивных термов вычисляется в преобразованных признаках и затем группируется по исходным факторам. Сплайны и one-hot колонки принадлежат исходному признаку. Ridge/GAM используют коэффициенты, EBM — `eval_terms` при тождественной функции связи; константная модель даёт нулевые вклады. XGBoost объясняется TreeSHAP с явно заданным `tree_path_dependent`, одной обученной моделью и неизменной базой. Это модельная атрибуция, не причинность.

У TreeSHAP диагональ матрицы — основные эффекты, симметричная внедиагональная пара суммируется один раз. Взаимодействия двух преобразованных колонок одного исходного фактора включаются в его основной вклад. Полные SHAP-значения признаков поверх этих пар повторно не прибавляются. EBM-термы группируются по тому же принципу, без утверждения, что их значения совпадают с SHAP.

Поддерживается только неизменная парная подвыборка: одинаковые id и количество наблюдений, постоянная база сокращается в разности. Отдельно проверяется восстановление локальных прогнозов в каждом периоде и их изменения. Допуск для численной проверки: абсолютная часть 1e-6, относительная 1e-5 от модуля прогноза; для агрегата допускается сумма локальных допусков. Численная погрешность фиксируется отдельно. Необъяснённый остаток относительно фактической цели включает ошибку модели и эту измеренную погрешность, поэтому итоговый баланс сохраняется без изменения вкладов.

Состояние всего портфеля получает вклады выбранной прогнозной модели. Для сравнения кандидатов атрибуции вычисляются только на валидационной подвыборке; у победителя дополнительно — на тестовой. Проверка атрибуции не меняет выбор по тестовым данным. При неподдерживаемом методе или провале баланса сохраняется причина отказа и полный необъяснённый остаток вместо вымышленных эффектов.

## Устойчивость

Опционально повторять выборку обучающих кредитов с возвращением, переобучая весь pipeline на T0. Состав валидационного портфеля фиксирован; тестовая цель не используется. Внутреннее случайное состояние модели фиксируется, меняется только обучающая выборка. Для векторов непересекающихся вкладов `v` и `b` считать сходство `1 - sum(abs(v-b))/(sum(abs(v))+sum(abs(b)))`. Его среднее — `stability_score`; для нулевого опорного вектора оценка не определена. Это диагностическая метрика, а не вероятность правильности.

Дополнительно сохранять разброс, эмпирические квантили 2,5%/97,5%, частоту совпадения знака и корреляцию рангов модулей. Материальными считать опорные эффекты от 1% общей суммы модулей; правило сохраняется вместе с результатом. Короткий бутстрэп (например, 20 повторов) даёт предварительную диагностику, не калиброванный доверительный интервал. Неуспешные повторы не скрывать; при неполном наборе не выдавать итоговый score за проверенную устойчивость. Пороги 0.70 и 0.85 остаются настраиваемыми ориентирами, уверенность автоматически не повышается.

## Проверка

Проверить суммы локальных прогнозов и агрегатов, свёртку категорий/сплайнов, симметрию пар, остаток и смену периодов. Сопоставить линейные вклады с аналитической формулой, проверить взаимодействие на известной поверхности. Бутстрэп должен быть воспроизводимым, использовать только обучение и обнаруживать изменение знаков/величин. Сохранить JSON и локальные таблицы расчётов со ссылками из результата.

29 сентября 2026 года прошли 66 тестов, Ruff и строгая проверка типов 49 файлов. Проверены баланс всех пяти методов, смена периодов, группировка категорий/сплайнов, аналитическое линейное разложение, воспроизводимость бутстрэпа и независимость его вкладов от проверочных целевых значений. Отдельные отрицательные тесты проверяют смену знаков, отсутствие эффектов, неполные повторы и отказ от неверного баланса. Количественное восстановление всех нелинейных форм и калибровка критериев надёжности остаются дальнейшими задачами.

В [эксперименте на восьми сценариях](../../ml/attribution-stability-v1.md) завершены 580 повторных обучений. Для трёх исходных моделей XGBoost численная проверка атрибуции не пройдена, причины сохранены; их бутстрэп не выполнялся. Высокая устойчивость EBM при смене режима сопровождается большим остатком, поэтому подтверждает необходимость отдельной проверки прогнозного качества.
