# ADR 0008 Локальный интерфейс без LLM

Статус: Принято

## Контекст и варианты

Пользователь исключил этап LLM. Для законченного прототипа нужны загрузка CSV, просмотр проверенного результата и выгрузка расчётов. Синхронный HTTP-запрос блокирует ожидание, отдельная очередь задач избыточна для одного локального пользователя.

## Решение

FastAPI обслуживает локальные HTML/CSS/JS без внешних ресурсов. Один активный анализ выполняется отдельным процессом CLI, принадлежащим менеджеру приложения. Статус опрашивается по HTTP. Отмена, тайм-аут 30 минут и остановка приложения завершают группу принадлежащего ему процесса. Сервер рассчитан на одного пользователя и один процесс Uvicorn, адрес по умолчанию 127.0.0.1. Публичное развёртывание не входит в прототип.

Загрузка — тело text/csv, максимум 10 МиБ, 100 000 строк, 20 факторов и 128 суммарных категорий. Параметры валидируются, имя файла пользователя не используется. Идентификатор задания генерируется сервером. Выгрузка разрешает только JSON и CSV из завершённого манифеста, не модели joblib. Старые задания после перезапуска доступны как файлы, а не через менеджер в памяти. Рабочие файлы сохраняются локально для воспроизводимости.

Графики — условные сечения модели: меняется один или два числовых фактора при медианах/модах обучающей группы T0. Диапазон — 1–99 процентили этой группы. Для пары показывается f(x,y)−f(x,y₀)−f(x₀,y)+f(x₀,y₀). Это иллюстрация формы модели, не причинный эффект, не SHAP и не вклад в изменение портфеля. При корреляции сечения могут попадать в редкие сочетания. На синтетике отдельная диагностика сравнивает сечения с известной формулой T0; истинная формула не участвует в обучении.

## Последствия и проверка

Нет ключей API, отправки данных наружу или генерации свободного текста. Числа берутся из AnalysisState. Проверить загрузку, валидацию, завершение, отмену, ограничения файлов, баланс и работу экрана в браузере. Проверить сечения на известной квадратичной функции. AG-UI отключается с явным ответом 410; сохранённый каркас LLM не участвует в работе.
