# Журнал практики

Статус: Реализовано

[Журнал Пермякова Германа Алексеевича](Журнал_практики_факторный_анализ_NPV.docx) подготовлен на основе [сохраненного оригинала](Журнал_практики_оригинал.docx). Содержание адаптировано к проекту факторного анализа NPV: задание, план, проект отзыва руководителя и отчет обучающегося. Отзыв требует проверки и подписи руководителя; оценка оставлена пустой.

По указанию пользователя указаны группа М8О-407Б-23, организация Т1, встречи в МАИ и примерный период 28.09–13.10.2026. Даты этапов распределены внутри этого периода. В блоках инструктажа и утверждения руководителем от МАИ по уточнению пользователя перенесено ФИО «Грубенко М.Д.» из снимка и указана дата 8 октября 2026 года. Остальные неизвестные ФИО руководителей, оценка и даты утверждения оставлены для заполнения. Исходные сертификаты другого студента заменены схемой этапов, сравнением измеренных ошибок и итогами проверки проекта.

Изменены только текст и три иллюстрации внутри исходного DOCX. Стили, геометрия страниц, таблицы, параметры абзацев, оформление подписей, размеры и размещение рисунков, колонтитулы и нумерация сохранены. Численные результаты взяты из [итогового аудита](../completion-audit.md); текущие границы поставки — из [ADR 0005](../architecture/decisions/0005-final-prototype-without-llm.md).

При изменении проекта обновлять содержание журнала по проверенным результатам, затем выполнять постраничную визуальную проверку. Оригинал не редактировать. Реквизиты и календарный план изменять только по уточнениям пользователя.

После готовности отчёта пользователь поручил продолжить полную реализацию проекта, включая LLM по [ADR 0009](../architecture/decisions/0009-complete-analysis-and-verified-llm.md). В этой поставке готовый журнал сохранён без изменений по указанию пользователя. Его прежние результаты и границы относятся к моменту подготовки; актуальная реализация и новые проверки публикуются в [аудите проекта](../completion-audit.md).

## Проверка готового файла

Журнал содержит 7 страниц, как оригинал. Все страницы визуально проверены после рендеринга. Состав частей DOCX совпадает с оригиналом; изменены только `word/document.xml` и три исходных PNG. Структура XML после исключения текстовых значений совпадает: свойства абзацев, шрифтов, таблиц и страниц не изменены. [Реквизиты](metadata.json) сохраняют предоставленные пользователем сведения и примерные сроки.
