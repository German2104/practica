## Зависимости и порядок

Данные → контракт цели → протокол → baseline и кандидаты → проверка вкладов/устойчивости → выбор на валидации → отдельный тест → диагностические формы и важность → каталог фактов → проверенный ответ LLM. Истинная синтетическая формула используется только после обучения для проверки восстановления. Тестовая цель не используется для настройки или переизбрания.

Этот порядок выполнен: локальные части и серии завершены, затем пользователь настроил ключ, сервис перезапущен, настоящие контрольные вопросы и чат прошли проверку. [Результаты LLM и обнаруженный отказ](ml/llm-verification.md); [команда повторения](development/README.md#подключение-openrouter).

Историческая [серия seed 2026](ml/confirmation-v2.md), [три окна UCI](ml/uci-v1.md) и [формы всех моделей](ml/recovery-v2.md) сохранены отдельно. Новые результаты не заменяют прежние.

## Границы применимости

Реальные счета UCI наблюдаются, однако `model_npv` задана учебной формулой. Это не измеренный банковский NPV, не прогноз дефолтов и не полноценный расчёт EC. Поддерживается парный состав клиентов; входы и выходы требуют отдельной методологии. Причинность и промышленная банковская надёжность не подтверждены. Сборка Docker не проверена: работающая служба Docker отсутствует.
