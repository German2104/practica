# Получение и подготовка Freddie Mac Release 47

Статус: Реализовано

Проверено 29 сентября 2026 года на официальном открытом образце и искусственных согласованных записях. Годовая исследовательская выборка ещё не получена. Решение и альтернативы — [ADR 0002](../architecture/decisions/0002-freddie-import-and-quality-gate.md).

## Получение источников

После установки окружения из [инструкции разработки](../development/README.md), из корня проекта:

```bash
.venv/bin/python scripts/prepare_dataset.py download-sample
```

Команда проверена: в `data/raw/freddie_mac/release47/` сохранены три официальных файла и `manifest.json` с происхождением каждого. Источники: [образец ZIP](https://www.freddiemac.com/fmac-resources/research/docs/release-47-sample-files.zip), [схема полей XLSX](https://www.freddiemac.com/fmac-resources/research/pdf/file_layout_july_2026.xlsx), [руководство PDF](https://www.freddiemac.com/fmac-resources/research/pdf/general_user_guide_july_2026.pdf). Это образцы формата, а не годовая выборка Clarity.

Ссылки и ожидаемые SHA-256 закреплены в [sources.py](../../src/ec_analysis/data/sources.py). Повторный запуск сверяет локальные файлы и использует их без сети. При несовпадении суммы существующий файл сохраняется, команда сообщает ошибку. Новая загрузка публикуется только после проверки, временные файлы удаляются при сбое. Манифест обновляется после каждого успешного файла; если ранее сохранённый файл не имеет записи о получении, время загрузки остаётся неизвестным.

## Проверка образца

```bash
.venv/bin/python scripts/prepare_dataset.py inspect \
  --archive data/raw/freddie_mac/release47/release-47-sample-files.zip \
  --report data/reports/release47-public-quality.json
```

Фактический результат сохранён в [JSON](../../data/reports/release47-public-quality.json):

| Показатель | Значение |
| --- | ---: |
| Строк выдач / уникальных кредитов | 1000 / 1000 |
| Строк истории / уникальных кредитов | 1011 / 12 |
| Общих кредитов | 0 |
| Кредитов истории без записи выдачи | 12 |
| Дубликатов ключей в каждом файле | 0 |
| Некорректных значений в проверяемых полях | 0 |

Код завершения **2** здесь ожидаем: `ready_for_pairing=false`, объединение отклонено. Это результат проверки качества. Идентификаторы не заменяются для искусственного совпадения. `prepare` также откажет для этого архива.

## Контракт подготовки

Читатель [freddie_mac.py](../../src/ec_analysis/data/freddie_mac.py) поддерживает стандартную схему Release 47: 31 поле выдач и 35 полей истории, разделитель `|`, без заголовка. Можно передать ZIP с одной однозначной парой файлов или два локальных файла. ZIP читается без извлечения. Другие релизы и расширенные наборы не угадываются по содержимому.

Проверяются ширина строк, непустые ключи, дубликаты `id` и `(id, reporting_month)`, календарные месяцы, конечность и допустимые диапазоны выбранных числовых полей. Точные имена, специальные коды и диапазоны заданы в [quality.py](../../src/ec_analysis/data/quality.py), который является основным источником этих правил. Это не полная проверка всех экономических полей исходника.

Ставки, DTI и LTV переводятся из процентов в доли единицы. Балансы сохраняют денежные единицы источника. Исходный `original_ltv` и текущий `estimated_ltv` хранятся отдельно; отсутствие одного не подменяется другим. Пропуски сохраняются, импутации нет. NPV, EC, PD и LGD не рассчитываются и не добавляются.

Подготовка требует двух существующих месяцев в порядке времени и непустой общей подвыборки кредитов. Экспортируются её признаки, `id`, `period` и `as_of_date`; первое число месяца в `as_of_date` обозначает месяц отчётности, а не фактический день наблюдения. В отчёте остаются числа вошедших/вышедших кредитов и суммы долга для всех и для общих кредитов. При пропуске баланса в выбранных месяцах расчёт этих сумм блокируется.

Пример ниже — **шаблон для будущих локальных файлов**, не результат запуска годовой выборки. Имена и месяцы нужно заменить своими; сама ветка `prepare` проверена интеграционным тестом на искусственных строках.

```bash
.venv/bin/python scripts/prepare_dataset.py prepare \
  --origination data/raw/my_sample/orig_2025Q4.txt \
  --performance data/raw/my_sample/perf_2025Q4.txt \
  --source-kind research_sample \
  --initial-month 202601 --final-month 202602 \
  --output data/processed/freddie-predictors.csv \
  --report data/reports/freddie-quality.json
```

CSV пока не готов для обучения NPV: сначала нужен отдельный расчёт целевой метрики и отбор доступных на дату факторов. Произвольная отметка `research_sample` не подтверждает качество источника.

## Ограничения и воспроизводимость

- Загрузка ограничена 20 МБ на официальный файл; читатель — 2 млн строк на таблицу и 512 МБ на элемент ZIP. Обработка хранит таблицы в памяти. Для больших историй потребуется отдельное чтение частями.
- Счётчики пропусков относятся ко всем колонкам после предусмотренной нормализации, проверки числовых диапазонов — только к выбранным полям.
- Проверки временной доступности факторов, распределений и выбросов на исследовательской выборке ещё предстоят.
- Исходники и подготовленные записи исключены из Git; агрегированный отчёт хранится в `data/reports/`. Контрольные суммы источников и подготовленного CSV, версия импортёра и выбранные месяцы сохраняются в отчёте.
- Тесты: [получение файлов](../../tests/test_data_acquisition.py), [импорт и подготовка](../../tests/test_freddie_import.py). Они используют искусственные записи; строки кредитов из официального архива не копируются в тесты.
