# Окружение запуск и проверки

Статус: Реализовано

## Подготовка

Требуются Python 3.12 и uv. Зависимости закреплены в `uv.lock`:

```bash
uv sync --locked --extra ml
```

Базовый запуск без extra `ml` сравнивает среднее, Ridge и GAM; недоступные дополнительные модели получают явный статус. На macOS для XGBoost/Interpret требуется OpenMP: в текущем окружении установлен Homebrew `libomp`. Dockerfile для Linux включает `libgomp1` и установку по lock-файлу. Docker-клиент обнаружен, но служба не запущена: сборка контейнера не подтверждена.

## Локальный интерфейс

```bash
uv run uvicorn ec_analysis.api.app:app --host 127.0.0.1 --port 8000 --workers 1
```

Открыть `http://127.0.0.1:8000/`. Сервис запускался и проверен в браузере: пример CSV → расчёт → вклады и остаток → сравнение → условные графики → ссылки JSON/CSV. Также проверен полный веб-анализ CSV UCI с 29 056 клиентами: завершение за 148,7 с, принятое объяснение. Веб-сценарий использует случайное разбиение; итоговая CLI-серия UCI — постоянные группы, поэтому её числа отличаются. Аналитика работает без ключа. LLM восстановлена по ADR 0009; проверенный поток доступен через `/ag-ui` после локальной настройки OpenRouter.

Рабочая модель — одна GAM с парными эффектами; три настройки регуляризации и 20 повторов выполняются всегда. Один активный расчёт выполняется отдельным процессом; доступны отмена и тайм-аут 30 минут. Загрузка ограничена 10 МиБ, 100 000 строк, 20 факторов и 128 кодируемых признаков. API-контракты и коды ошибок — в [архитектуре](../architecture/design.md).

`EC_DATASET_PATH`, `EC_TARGET_METRIC`, `EC_JOBS_DIRECTORY` задают пример и каталог заданий; шаблон — `.env.example`. Адрес и порт передаются Uvicorn явно. Использовать один worker: менеджер заданий находится в памяти. После перезапуска файлы сохраняются в `data/jobs`, но реестр HTTP-заданий пуст. Авторизации и публичного многопользовательского режима нет.

## Подключение OpenRouter

В локальном `.env` заполнить `EC_OPENROUTER_API_KEY` и `EC_LLM_MODEL` (идентификатор выбранной модели OpenRouter с поддержкой tool calls). В примере выбран `openai/gpt-4.1-mini`, ключ оставлен пустым. Локальный `.env` подготовлен с этими значениями, если его ранее не было. Ключ не присылать в чат, не включать в Git и не выводить в логи. После настройки перезапустить сервис: конфигурация читается при запуске.

Чат появляется после завершения анализа. Модель получает вопрос и каталог агрегированных фактов. Она выбирает факты и детализацию; рендерер формирует русский текст. Свободная генерация неподтверждённых бизнес-утверждений не поддерживается. Каждое число и утверждение имеет источник; остаток, причины низкой уверенности и модельная природа `model_npv` обязательны. При непроверенном ответе текст не показывается.

Установленные и проверенные в локальном контракте версии: `pydantic-ai-slim 2.51.0`, `ag-ui-protocol 0.1.22`, `openai 3.22.1`, клиент `httpx2`. Адаптер создаёт события протокола после полной проверки ответа. Это обеспечивает проверку до первого числового фрагмента, но увеличивает задержку до появления текста. [Pydantic AI AG-UI](https://pydantic.dev/docs/ai/integrations/ui/ag-ui/) · [OpenRouter API](https://openrouter.ai/docs/quickstart).

Для первой проверки выбран [GPT-4.1 Mini](https://openrouter.ai/openai/gpt-4.1-mini): официальная страница OpenRouter подтверждает поддержку tool calls и структурированных ответов (проверено 02.10.2026). Это начальная настройка, а не подтверждённое качество нашего сценария; модель можно заменить через `EC_LLM_MODEL`.

Команда выполненной живой проверки 02.10.2026 (для повторения выбрать новый выходной файл):

```bash
uv run python scripts/check_llm.py data/experiments/completion-v3/mixed/analysis.json --output data/reports/openrouter-live-v3.json
```

Пять вопросов проверяют общее объяснение, важность, формы, попытку скрыть остаток/придумать числа и вопрос вне данных. Требуются соответствующие категории фактов и явный отказ для неподдержанного вопроса. Выходной файл не перезаписывается. Проверка без настройки завершилась кодом 2 без внешнего запроса; реальные SDK-запрос и SSE проверены тестами с подменённым ответом. Тестовый ответ отличён от настоящей модели. После локальной настройки ключа основные пять вопросов прошли, дополнительно прошли вопросы о LTV × PD и детализации объёма. [Живые результаты](../ml/llm-verification.md) сохраняют также отказы до исправления инструкции. Чат в браузере проверен на текущем интерфейсе с настоящим OpenRouter.

## Один эксперимент

```bash
uv run python scripts/run_benchmark.py data/portfolio_data.csv --advanced --tune --bootstrap-repeats 10 --output-dir data/experiments/my-run
```

Всегда выбирать новый выходной каталог. `--target` задаёт целевую колонку, `--features` — разрешённые факторы, `--seed` — случайное состояние, `--stable-split` — неизменяемую между окнами группу клиента, `--workers 1` ограничивает параллелизм моделей. `--no-attribution` оставляет только прогнозный сценарий. Бутстрэп допустим при атрибуции и N ≥ 5; политика принятия требует N ≥ 10.

Каталог содержит `analysis.json`, `split.json`, `sections.json`, `profile.json`, `global-importance.json`, `shapes.json`, `parameter-sensitivity-{model}.json` при подборе, модели `.joblib`, прогнозы, атрибуции и бутстрэп CSV. Последним создаётся `manifest.json` со статусом complete, SHA-256 данных/файлов/исходников и версиями библиотек. Существующий каталог не перезаписывается. Не загружать чужие joblib-файлы: API принимает только CSV, экспорты ограничены JSON/CSV собственного результата.

## Данные и серии

```bash
uv run python scripts/prepare_uci_dataset.py --output data/processed/uci-example.csv
uv run python scripts/run_uci_benchmark.py --output-dir data/experiments/uci-repeat --seed 2026 --bootstrap-repeats 10
uv run python scripts/run_synthetic_benchmark.py --advanced --tune --samples 5000 --seed 2026 --bootstrap-repeats 10 --output-dir data/experiments/synthetic-repeat
```

UCI загружается публично и проверяется по SHA-256, при совпадающем кэше повторного скачивания нет. Три временных окна используют общую принадлежность клиентов к группам. Цель — `model_npv`, допущения [документированы](../data/uci-credit.md). Freddie Mac Release 47 проверяется отдельным [импортёром](../data/release47-import.md); открытый образец несогласован по идентификаторам.

На текущем компьютере SHAP запускался с переменными `MPLCONFIGDIR=/private/tmp/practica-mpl` и `XDG_CACHE_HOME=/private/tmp/practica-cache` из-за ограничений домашнего кэша. Это локальные настройки, не обязательные пути для другого компьютера.

## Проверки

```bash
uv run pytest -q
uv run ruff check src scripts tests
uv run ruff format --check src scripts tests
uv run mypy src scripts
```

Проверенный результат текущей реализации: **123 теста**, Ruff без замечаний, strict mypy для **63 исходных файла** и четыре файла аудита/повторения (67 всего). Три предупреждения PendingDeprecationWarning относятся к цветовым картам SHAP/Matplotlib и не подавляются. Проверяются независимость тестовой цели, истинные формулы, баланс и численные отказы, стабильность групп между окнами, подготовка UCI, загрузка/завершение/отмена/тайм-аут API и запрет выдачи моделей.

Исходные серии seed 42 сохранены: [первое сравнение](../ml/synthetic-comparison-v1.md), [разложения и бутстрэп](../ml/attribution-stability-v1.md). Новые результаты сохраняются отдельно. Содержательную проверку модели нельзя заменить успешным запуском тестов.

## Одна рабочая GAM

Веб-задания всегда используют `stable_gam`, три alpha и 20 повторов. Режимы
трёх/семи семейств удалены с рабочего экрана. Исследовательское сравнение
`run_benchmark.py` сохранено; [методика и ограничения](../ml/single-gam.md).

```bash
uv run python -m scripts.run_analysis data/portfolio_data.csv --seed 2028 --workers 1 --output-dir data/experiments/single-gam-repeat
uv run python docs/ml/evaluate_single_gam.py --output data/reports/single-gam-v4-audit-repeat.json
uv run python docs/ml/replay_completion.py --output data/reports/completion-v3-audit-repeat-frozen.json
```

`run_analysis` запускается как модуль с `-m`; по умолчанию одна семья и 20 повторов.
Аргументы исследовательского сценария сохранены, явные overrides в CLI записываются
в результатах; рабочий API не сокращает проверки. Новые выходные каталоги обязательны.

Прямой исторический аудит v3 с текущими аналитическими исходниками отклоняется:
контрольные суммы изменились. `replay_completion.py` проверяет и извлекает старый
снимок во временный каталог, использует старые импорты и заново проверяет старые
артефакты без перезаписи. Повтор завершён; исходный отчёт по практике сохранён.
