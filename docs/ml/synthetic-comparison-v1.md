# Сравнение моделей на известных синтетических зависимостях

Статус: Реализовано

Исторический запуск до подключения атрибуции. Текущий CLI по умолчанию дополнительно рассчитывает вклады; прогнозные параметры и разбиение остаются описанными ниже. Новые диагностики сохраняются в отдельном отчёте.

Выполнено 29 сентября 2026 года: 8 сценариев, 1500 кредитов (3000 строк) в каждом, seed=42. Источник чисел — [машинный отчёт](../../data/reports/synthetic-comparison-v1.json). Сценарии используют одинаковые признаки и разбиение; меняется только известная формула целевой метрики.

## Протокол

По [ADR 0003](../architecture/decisions/0003-forward-benchmark.md): 900 обучающих, 300 валидационных и 300 тестовых кредитов, без пересечений. Обучение использует только T0; RMSE/MAE считаются на T1. Подписанный остаток кандидата относится к разности T1−T0 его валидационной подвыборки. Выбранная по валидации модель проверяется на тесте без переобучения. Параметры зафиксированы до запуска, поиск гиперпараметров и проверка устойчивости не выполнялись.

## Выводы и ограничения

- На линейном сценарии меньшую валидационную ошибку дал Ridge; на остальных — EBM. Это результат этого фиксированного набора данных и параметров, а не универсальное превосходство модели.
- В `regime_shift` появляется не наблюдаемый по факторам сдвиг −60 на кредит в T1. Большой остаток показывает ограниченность переноса; победитель по RMSE не объявляется надёжным объяснением.
- GAM здесь — сумма одномерных кубических сплайнов с регуляризованной линейной регрессией и тождественной функцией связи; парных термов в нём нет. Поэтому его возможности на взаимодействиях ограничены.
- Предсказательная точность на нелинейной формуле ещё не доказывает обнаружение правильных факторов. SHAP, термы EBM и восстановление эффектов будут проверяться отдельным этапом.
- Все состояния имеют `confidence_level=low` и `selection_status=prediction_only`; устойчивость не измерялась. Вклады пока пусты, верхнеуровневый остаток равен полному изменению всего входного портфеля.
- Дат в этой синтетике нет: используется относительный порядок T0→T1. Многопериодная проверка, реальные данные и оценка памяти не выполнены.

## Воспроизведение и артефакты

После установки окружения с `ml` (см. [разработку](../development/README.md)) выполнена команда:

```bash
.venv/bin/python scripts/run_synthetic_benchmark.py --advanced --samples 1500 --seed 42 --output-dir data/experiments/forward-v1
```

Для повторения нужен новый каталог, например `data/experiments/forward-v1-repeat`; существующий запуск не перезаписывается. В каталоге находятся исходные CSV, отдельные `.truth.json` с генерирующими компонентами, а также для каждого сценария `analysis.json`, `split.json`, модели `.joblib`, прогнозы CSV и `manifest.json` с версиями и SHA-256. Большие локальные артефакты исключены из Git; сводный JSON сохранён в `data/reports/`.

Версии запуска: Python 3.12.13, scikit-learn 1.9.1, XGBoost 3.4.1, Interpret 0.7.8. На этом Mac для XGBoost установлен libomp 23.1.2. Полные Python-версии и хеши кода находятся в манифестах. Суммарное время запуска: 29.84 с; оно включает импорт и сохранение артефактов. Сравнение производительности по одному запуску не проводится.

## Источники реализации

Использованы официальные описания [SplineTransformer](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.SplineTransformer.html), [EBM](https://interpret.ml/docs/ebm.html) и [XGBoost](https://xgboost.readthedocs.io/en/stable/python/python_api.html#xgboost.XGBRegressor). Конкретные фиксированные настройки описаны в [CandidateFactory](../../src/ec_analysis/engine/candidates.py); известные формулы — в [SyntheticFormula](../../src/ec_analysis/data/synthetic.py).
