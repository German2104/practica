# Дополнение исходного задания: серия v3

Статус: Реализовано

## Протокол

Выполнена независимая серия **13 сценариев × 5000 клиентов**, seed 2027, 7 семейств, по 3 профиля каждой неконстантной семьи и 10 повторов бутстрэпа. Дополнительно проверены три временных окна UCI. [ADR 0009](../architecture/decisions/0009-complete-analysis-and-verified-llm.md) принят до серии; пороги после просмотра итогового теста не менялись.

Клиенты 60/20/20; обучение — T0. Вариант внутри семьи выбирается по RMSE валидации T1. Из кандидатов, прошедших проверки прогноза, остатка, бутстрэпа и параметров, выбирается минимальная валидационная RMSE. Если принятых нет, лучший прогноз сохраняется с отказом подтверждать объяснение. Затем проверяется только выбранная модель на независимом тесте; отказ теста не вызывает переизбрания. Истинная формула не используется при обучении, выборе и автоматической классификации формы.

**Подтверждены 9 из 13 синтетических объяснений и 3 из 3 окон UCI.** Отказы — результаты исследования. Синтетическая серия заняла 3520,80 с, UCI — 358,28 с; это время данных запусков на текущем компьютере. [Определения метрик](metrics.md).

### Причины четырёх отказов

- **credit:** прогноз и тест проходят пороги, но на валидации минимальное согласие знаков между профилями параметров **0.857143 < 0.90**. Сходство 0.955619 и бутстрэп 0.968618 не отменяют этот отказ. В семье GAM с парами результат оставлен диагностическим.
- **observable_regimes:** валидация принята, но модуль остатка на независимом тесте / масштаб существенности **0.184109 > 0.15**. Тип зависимости объёма распознан как `regime`; правильный тип формы не гарантирует устойчивое объяснение перехода. Модель не переизбиралась после теста.
- **regime_shift:** скрытая смена функции в T1; ошибки прогноза и остаток превышают пределы. Высокая устойчивость внутри прежнего обучения не обнаруживает любую смену режима.
- **no_signal:** нулевая прогнозная ошибка и нулевой баланс не дают ненулевых эффектов для проверки устойчивости. Бутстрэп/параметры не дают определённой оценки; надёжное объяснение не подтверждено.

## Восстановление форм без доступа детектора к истине

После завершения серии все 91 сохранённая синтетическая модель проверена на одинаковых условных сетках обучения T0: **455 сечений и 910 парных контрастов**. Истинные значения берутся из отдельной формулы генератора. Эти ошибки не являются истинными SHAP-вкладами или независимой тестовой RMSE и не используются для переизбрания.

| Сценарий | Фактор | Тип у выбранной модели | RMSE сечения выбранной модели | RMSE сечения Ridge |
| --- | --- | --- | ---: | ---: |
| threshold | ltv | complex | 0.28885 | 10.808 |
| full_saturation | volume | saturation | 0.00115895 | 9.31654 |
| u_shaped | ltv | u_shaped | 3.24651e-06 | 7.05367 |
| inverted_u_shaped | ltv | inverted_u_shaped | 4.59313e-06 | 11.2859 |
| observable_regimes | volume | regime | 0.351308 | 51.4211 |

Пороговая зависимость у выбранной GAM с парами осталась `complex`: слабый наклон перед изломом не прошёл фиксированное правило почти плоской ветви. RMSE восстановления сечения 0.288850 при этом существенно меньше линейного baseline. Одномерная GAM в той же серии распознала `threshold`, её ошибка сечения 0.960533. Это зафиксированный предел классификатора; пороги не подгонялись после итоговых оценок.

## Аудит и воспроизводимость

Проверены **16 валидированных состояний, 688 файлов результатов и 1534 ссылки на расчёты**; в серии выполнены **893 успешных повторных обучения бутстрэпа**. Сводки совпадают с отдельными состояниями и контрольными суммами манифестов, входов и истинных формул. Исходный DOCX сохранён с прежним SHA-256.

Все эксперименты имеют одну версию исходников `5062061eb904a32cda814083dc931a9b4fb9bd9a6b8b5a5e1f479dcc501bc309`. Перед последующей доработкой текста причин отказа LLM сохранён [снимок 62 исходных файлов](../../data/reports/completion-v3-source.zip), включая lock-файл. Он не содержит .env или ключа. Аналитические исходники совпадают со снимком; после серии обновлены только четыре модуля интерпретации: evidence.py, fact_checker.py, interpreter.py и prompts.py. Изменения относятся к тексту причин отказа, явному списку обязательных фактов и сообщениям исправления для LLM; расчёты не менялись.

[Первый аудит](../../data/reports/completion-v3-audit.json) и [окончательный аудит со снимком](../../data/reports/completion-v3-audit-final.json) сохранены отдельно. [Проверочный модуль](evaluate_completion.py) сверяет каждый SHA-256 снимка и текущие аналитические исходники (исключения — только четыре явно перечисленных модуля интерпретации с записанными новыми SHA-256), баланс, ссылки, принятие и восстановление всех моделей. Он загружает joblib только из двух фиксированных собственных каталогов; не применять к сторонним моделям.

Повторение с новым выходным файлом:

```bash
uv run python -m docs.ml.evaluate_completion --output data/reports/completion-v3-audit-repeat.json
```

Исследовательская диагностика не меняет сохранённые модели, выбор или тестовые оценки. При корреляции условная сетка может выходить за плотную область наблюдений. Типы формы, бутстрэп и три профиля параметров не охватывают все неопределённости.
