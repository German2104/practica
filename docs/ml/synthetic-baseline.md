# Пробный запуск Ridge на синтетическом портфеле

Статус: Реализовано

Исторический отчёт ранней версии. Текущий CLI использует новый протокол и не воспроизводит эти числа той же командой; актуальное сравнение — [forward_grouped_v1](synthetic-comparison-v1.md). Ниже сохранены условия и результаты исходного запуска.

Дата запуска: 29 сентября 2026 года. Проверяется работоспособность существующего CLI и расчёта прогнозов. Это предварительная точка отсчёта; окончательный протокол оценки из [ML-документа](README.md) ещё не реализован.

## Данные и запуск

Источник — [демонстрационный CSV](../../data/portfolio_data.csv), созданный [генератором](../../scripts/generate_dataset.py) с `samples=500`, `seed=42`: 500 кредитов, 1000 строк за `T0` и `T1`. `npv` — искусственная метрика по формуле генератора. Код и данные пока не закоммичены; их контрольные суммы, параметры и версии зафиксированы в [метаданных](../../data/reports/synthetic-baseline-metadata.json).

Проверенная команда:

```bash
.venv/bin/python scripts/run_benchmark.py data/portfolio_data.csv > data/reports/synthetic-baseline.json
```

Модель `Ridge(alpha=1.0)`, без масштабирования. В признаки входят все числовые колонки кроме целевой. Разделение по уникальным кредитам: 400 для обучения, 100 для валидации, `random_seed=42`; обе даты каждого кредита остаются вместе. Обучение и валидация содержат по два наблюдения на кредит. Независимого финального теста пока нет.

## Что ещё не доказывает этот запуск

Вкладов факторов и взаимодействий пока нет: верхнеуровневый `unexplained_remainder` равен полному изменению −8049.0444. Он отличается от ошибки прогноза в строке кандидата, потому что предсказанное изменение ещё не разложено по факторам. Уверенность `low`, устойчивость не измерялась (`null`). Ridge отмечен выбранным как единственный кандидат; сравнения с нелинейными моделями ещё не было.

Следующие шаги: добавить масштабирование внутри обучающей части, ориентир среднего, одинаковые разбиения для всех кандидатов, независимый расчёт портфельной ошибки, сохранение моделей и сценарии синтетических нелинейностей. Затем сравнивать модели и проверять разложения по [плану](../plan.md).
