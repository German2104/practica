# Одна основная GAM

Статус: Реализовано

Рабочий интерфейс использует только **GAM со сплайнами и парными эффектами**, версия
`stable_gam`. Поиск между семьями исключён из рабочего процесса по указанию
пользователя. Исследовательские сравнения остаются доступными отдельно.
Решение и заменяемые контракты — [ADR 0010](../architecture/decisions/0010-single-gam.md).

## Почему эта модель

Прежняя GAM с парами покрывала нелинейности и прошла все три окна UCI на валидации
разработки v3. В новой версии удалены произведения и квадраты сплайнов внутри одного
фактора: его кривизну уже описывает сплайн. Взаимодействия получают усиленный
квадратичный штраф, чтобы слабые пары меньше меняли разложение. На валидации
кредитного примера seed 2027 проверены множители 1, 10, 100, 1000 и 10000;
для 1000 сходство вкладов между alpha составило 0.936, совпадение значимых знаков
1.000. Настройки зафиксированы **до** подтверждающей серии seed 2028.
Новая версия не объявляется лучшей для любых данных: это фиксированный компромисс
между гибкостью, прозрачностью и устойчивостью рабочего анализа.

## Как она работает

```mermaid
flowchart LR
    A[Пары T0 / T1] --> B[Обучение только на T0]
    B --> C[Сплайны факторов и произведения разных факторов]
    C --> D[Ridge с усиленным штрафом пар]
    D --> E[Alpha по валидации]
    E --> F[Валидационные вклады и 20 повторов]
    F --> G[Замороженная модель и независимый тест]
    G --> H[Портфельные вклады и подписанный остаток]
```

Прогноз имеет вид `b + Σ f_j(x_j) + Σ g_jk(x_j,x_k)`.
Каждая `f_j` — сумма кубических B-сплайнов одного фактора. `g_jk` — сумма
произведений центрированных базисов двух разных исходных факторов. Категории
представлены полными индикаторами; неизвестная категория даёт нулевой вектор
до центрирования. Пропуски и все центры вычисляются только по обучению T0.

Обучение минимизирует сумму квадратов ошибок плюс
`alpha × (Σ β_main² + 1000 × Σ β_pair²)`. Это одна Ridge-регрессия, а не смесь
семейств. Числовые настройки: шесть равномерных узлов, степень 3, линейная
экстраполяция, максимум 2500 термов. Alpha выбирается из `0.1, 1, 10` по
валидационной RMSE; остальные профили также сохраняются для проверки вкладов.
Итоговая модель не переобучается и не переизбирается по тесту.

Вклад фактора — сумма его термов на T1 минус сумма на T0. Парный вклад считается
отдельно один раз. Остаток = фактическое изменение − сумма всех вкладов.
База одинаковой модели сокращается на одинаковом составе клиентов.
Метод `centered_cross_factor_gam_delta_v1`. Центрирование задаёт правило
распределения эффектов, но не доказывает причинность.

## Подтверждающая серия

5000 клиентов в каждом синтетическом сценарии, seed 2028; обучение/валидация/тест
60/20/20, 20 переобучений на клиентах T0. Три окна UCI используют постоянные
группы клиентов. Проверяются прежние пороги: нормированная RMSE ≤ 0.15,
доля остатка по материальности ≤ 0.15, устойчивость ≥ 0.85,
совпадение значимых знаков ≥ 0.90. Определения — [metrics.md](metrics.md).
Здесь RMSE нормируется на разброс цели, поэтому 0.089 не означает «91.1% точности».

| linear | 0.2771 | 0.0076 | 0.9989 | Принято |
| threshold | 2.6198 | 0.0652 | 0.9950 | Принято |
| saturation | 0.3062 | 0.0064 | 0.9988 | Принято |
| u_shaped | 0.3556 | 0.0095 | 0.9988 | Принято |
| interaction | 1.2935 | 0.0338 | 0.9961 | Принято |
| mixed | 2.8090 | 0.0546 | 0.9950 | Принято |
| regime_shift | 60.8245 | 1.1816 | 0.9950 | Отказ |
| correlated | 0.7490 | 0.0131 | 0.9982 | Принято |
| no_signal | 0.0000 | 0.0000 | — | Отказ |

Приняты **8/13** синтетических сценариев и **1/3** окон UCI. Высокий бутстрэп
не заменяет другие проверки. `regime_shift` отклонён из-за скрытого сдвига и
остатка; `no_signal` не имеет измеримой устойчивости. Перевёрнутая U и видимые
режимы не прошли сходство вкладов при смене alpha; полное плато — знаки и
параметры. Два окна UCI не прошли долю остатка, несмотря на малую ошибку
отдельных прогнозов. После этих результатов параметры не менялись.
Это меньше принятых окон, чем в историческом выборе между семействами v3;
результат сохранён, запасная семья в рабочем приложении не включена.

UCI содержит реальные входы, но `model_npv` задан учебной формулой;
это не измеренный банковский NPV и не проверка модели дефолтов.

## Кредитный пример и baseline

На тех же данных и группах фиксированная линейная Ridge (`alpha=1`) дала RMSE
теста **28.8845**; новая GAM — **6.7200**, снижение ошибки **76.74%**.
Порог надёжности применён к GAM; сравнение baseline выполнено после заморозки
модели и не использовалось для подбора. Для кредитного примера сходство между
параметрами **0.9271**, знаки **1.0000**.

Для всего портфеля изменение −81 610.72, подписанный остаток −3 852.37
(−4.72% от абсолютного изменения). Остальные вклады дают −77 758.35.
Величины условные и синтетические. [Полное состояние](../../data/experiments/single-gam-v4/credit/analysis.json).

Демонстрационный CSV теперь содержит 5000 кредитов (10 000 строк), seed 2028.
[Прежний CSV из 500 кредитов](../../data/examples/portfolio-legacy-500.csv) сохранён;
разработка seed 2027 на такой малой выборке не прошла проверки прогноза,
бутстрэпа и параметров. Увеличение демонстрационной выборки не является
гарантией на других пользовательских данных.

Команды проверены через существующее окружение `.venv`; для повторов выбраны новые
выходные пути. Рабочий веб-процесс использует фиксированный seed 2026, поэтому
его разбиение отличается от подтверждающей серии seed 2028. Его результаты
записываются отдельно. Название `stable_gam` — идентификатор версии: при провале
любого обязательного критерия интерфейс показывает неподтверждённое объяснение.

[Повтор разработки](evaluate_gam_development.py) и
[валидационные измерения](../../data/experiments/single-gam-development-replay/validation.json)
сохраняют перебор штрафа отдельно: это повтор после подтверждения,
без использования тестовых целей и без изменения замороженных настроек.
Время отдельных вариантов в этом повторе не измерялось (`elapsed_seconds=0`
в записи профиля — технический заполнитель, не фактическое время).

Рабочий браузерный пример завершился за 3.02 с, seed разбиения 2026:
устойчивость 0.9862, RMSE теста 5.2576. Реальный OpenRouter вернул
проверенное объяснение с раскрытым источником остатка;
[протокол](../development/single-gam-ui-v4.json) отделён от серии seed 2028.
