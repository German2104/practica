# Факторный анализ EC и NPV

Локальный прототип объясняет изменение суммы целевой метрики между T0 и T1: основные факторы, взаимодействия и подписанный остаток. Рабочий анализ использует одну GAM с парными эффектами, показывает глобальную важность и формы зависимостей, сообщает об отказах проверок. Ответы на вопросы формируются проверяемой интерпретацией через OpenRouter; аналитика работает без ключа.

## Быстрый старт

```bash
uv sync --locked --extra ml
uv run uvicorn ec_analysis.api.app:app --host 127.0.0.1 --port 8000 --workers 1
```

Открыть [локальный интерфейс](http://127.0.0.1:8000/), нажать «Использовать пример» и «Начать анализ». Рабочий расчёт — одна GAM, три настройки регуляризации и 20 повторов бутстрэпа. Пример содержит 5000 кредитов. Требуются Python 3.12 и uv; особенности OpenMP и контейнера — в [инструкции](docs/development/README.md).

## Возможности

- Парный CSV с числовыми и категориальными факторами; целевая колонка выбирается пользователем.
- Основная модель — GAM с регуляризацией и парами; прежние семь семейств доступны для исследовательского сравнения через CLI.
- Раздельные клиенты обучения, валидации и теста; подбор не использует тестовую цель.
- Нативные термы и TreeSHAP, явные пары без двойного счёта, арифметический баланс.
- Бутстрэп и смена параметров, нормированная ошибка, материальность остатка, причины принятия и отказа.
- Профиль CSV, глобальная важность отдельно от вкладов, численная диагностика порога, насыщения, U-форм и режимов.
- LLM выбирает проверенные факты по вопросу; русский текст и источники каждого утверждения проверяются до потокового показа.
- Локальный экран, графики, отмена расчёта, сохранённые JSON/CSV и манифесты.

**Проверено:** 123 теста, Ruff, strict mypy; OpenRouter SDK с подменённым сервером, семь настоящих вопросов к GPT-4.1 Mini и живой браузерный чат с источниками. [Подключение и проверки](docs/development/README.md#подключение-openrouter). Dockerfile подготовлен, но сборка не проверена: служба Docker в окружении не запущена.

## Данные и результаты

Доступны тринадцать воспроизводимых синтетических сценариев и реальные карточные остатки UCI. В UCI цель `model_npv` вычисляется по отдельно указанным допущениям; малая ошибка её восстановления не является качеством прогноза дефолтов. Открытый образец Freddie Mac несогласован по идентификаторам, его объединение корректно отклоняется; аккаунта Clarity нет.
