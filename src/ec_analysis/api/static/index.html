Как читать результат

Остаток сохраняется со знаком. Даже устойчивое объяснение может быть отклонено из-за ошибки прогноза.

Меняем один фактор при фиксированных медианах и модах обучающей выборки. Это сечение модели, а не вклад в изменение портфеля.

Синий — положительный, оранжевый — отрицательный совместный эффект. При корреляции факторов некоторые сочетания могут быть редкими.
